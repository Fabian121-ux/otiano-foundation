# Approved OFD landing photographs

Upload the supplied **landing-photos.zip** to this folder on branch
`improve/landing-photos-and-home-cta` and commit it.

The workflow checks the exact original photographs, updates the React hero
and removes the transfer ZIP. No production deployment takes place.

Mapping:
- Landing 2 / OFD team photo → main “Opportunity for All” hero slide
- Landing 3 / school pupils → Education slide
- Landing 1 / OFD presenter holding microphone → Community Impact slide
- The Healthcare slide retains its existing photograph, as no clinical/healthcare photo was supplied.

Do not invent programme dates, events or locations based on these images.
